Example Prompts and Outputs
---------------------------
 
Representative paraphrases of prompts and responses.
 
1. Rafael Nadal's File Is Different
 
   Prompt:
   "The package works for Serena Williams but not for Rafael Nadal.
   Column 16 has values like 22.264202601. Why?"
 
   Output:
   Explained that male career files give the opponent's age instead
   of the birthdate, and that the player's own birthdate is in a
   separate file. Suggested checking which format a file uses before
   calculating ages, which became _has_birthdates().
 
2. Players With No Career File
 
   Prompt:
   "Why does the package say Jannik Sinner doesn't exist? He has a
   page on Tennis Abstract."
 
   Output:
   Found that some players have a page but no Career.js file, and
   that Sinner only has an old file with 34 matches from 2018. I
   decided not to plot that file, because calling it his "career"
   would be misleading, and explained this limit in the README.
 
3. Tests Failing in a Fresh Clone
 
   Prompt:
   "pytest passes in my folder but fails after I clone the repo
   again. Why can't it find the package?"
 
   Output:
   Explained that pytest could not find the package in the src/
   folder and suggested adding pythonpath = ["src"] to
   pyproject.toml, which I did.
 
4. Installed but Cannot Import
 
   Prompt:
   "pip install worked, but import tennis_career fails."
 
   Output:
   Explained that pip and python in my terminal pointed to two
   different Pythons, and suggested using python -m pip install.
